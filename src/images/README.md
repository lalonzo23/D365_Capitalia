# images/

Coloca aquí iconos e imágenes que se publicarán como web resources
(`.png`, `.svg`, `.gif`, `.jpg`, `.ico`).

Convención de nombres en D365: `new_/images/<archivo>`.

Recomendaciones para iconos de cinta (ribbon):
- 16x16 px para iconos pequeños.
- 32x32 px para iconos grandes.
- Formato PNG con fondo transparente o SVG.
